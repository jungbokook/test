6. Frontend 분석 중 Backend API를 발견하면 Backend 내부까지 계속 분석해야 하는가?
7. Backend 기능 분석에서 MyBatis와 Oracle은 어떤 범위에서 사용하는가?
8. Chrome DevTools MCP, Code Index MCP, Oracle MCP의 역할을 각각 설명해줘.
9. 확인되지 않은 비즈니스 로직은 어떻게 처리해야 하는가?
10. 현재 단계가 끝난 후 다음 단계로 자동 진행해도 되는가?
